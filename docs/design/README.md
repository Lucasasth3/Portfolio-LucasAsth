## Como abrir a prévia interativa

A prévia é um arquivo HTML local. O GitHub não executa esse HTML e ela não está publicada no endereço da Vercel.

1. Clone o repositório ou use **Code → Download ZIP** no GitHub e extraia o conteúdo.
2. Abra a pasta `docs/design` no Explorador de Arquivos do Windows.
3. Abra `index.html` com Chrome ou Edge. Mantenha `telas.js`, as pastas de SVGs e os demais arquivos juntos.
4. Escolha **Wireframes** ou **Protótipo**, selecione uma página e alterne entre **Desktop** e **Mobile**.

No VS Code, use o botão direito em `docs/design/index.html` e escolha **Revelar no Explorador de Arquivos**. Depois, abra o arquivo no navegador. Abrir apenas a aba de código no editor não executa a prévia.

Não é necessário iniciar o Vite para essa prévia. O download do repositório serve apenas para visualizar os arquivos localmente; não altera o formato de entrega da tarefa.

## O que este material representa

São 22 wireframes de média fidelidade e 22 telas visuais em SVG: 11 páginas e estados, em desktop de 1440 px e mobile de 390 px. O material registra a versão do site de 21 de novembro de 2026; textos e detalhes podem ter evoluído depois dessa data.

A prévia local simula navegação e estados do formulário, sem enviar e-mails. Animações, busca de livros e integrações são demonstradas no site real. As telas do Figma não possuem conexões de protótipo.
